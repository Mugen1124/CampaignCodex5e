# Working with an AI assistant

**Optional.** Everything here can be done by hand. But because a campaign here is plain text files with clear conventions, an AI coding assistant that can read and edit files — such as Claude Code — can do a lot of the busywork: drafting session pages from a transcript, moving played prep back into an arc, adding NPCs from your notes, building encounters, checking for leaks.

## CLAUDE.md

The file `CLAUDE.md` in this folder tells an assistant how this project works: where things live, the conventions for This Session and the session pages, how the players' site stays safe, and what never to do (publish without asking, put secrets in public text). Claude Code reads it automatically; other assistants can be pointed at it. Edit it to add your own preferences.

## Things to ask for

- *"Write up the session from recordings/Session 2026-10-04 1900.transcript.txt."* — a draft session page, a "Previously…" recap, and a list of suggested data updates (who died, who moved, who got what), for you to review before anything changes.
- *"Move the played parts of This Session back into the arc, and set up Now for next session."*
- *"Add these NPCs from my notes"* (paste them) — with mentions, regions, and locations.
- *"Build an encounter for four level-3 characters at the lighthouse, hard."*
- *"Run the check and fix anything it finds."*

## Good habits

- **Review before it's installed.** Ask for a draft first, read it, then let it make the change.
- **Keep the recap readable.** The "Previously…" box is read aloud and shown to players: short sentences, in order, no clever phrasing.
- **Check names.** Transcripts mishear names; make sure the write-up uses the names in your data.
- **Watch what becomes public.** Anything mentioned in the public part of a session page appears on the players' site.
