# Encounters

**Active** lists the encounters you're prepping or running; **Archive** keeps the ones you're done with, which still show on their story pages. **Builder** makes new ones — by hand from every creature, the campaign's own and the SRD, or with the generator. Difficulty everywhere follows the party set at the top.
